# Apptio Cloudability Connector — Preparation

**Category:** C41. Cloud Cost Management (FinOps)  
**Status:** App Preparation Complete (Genuinely Vendor-Specific)  
**Standard:** APP_PREPARATION_STANDARD.md

## 1. Паспорт коннектора
- **Название:** Apptio Cloudability Connector (`cloudability-connector`)
- **Официальный портал вендора:** https://cloudability.com
- **Базовый API:** `https://api.cloudability.com/v3`
- **Модель аутентификации:** API Key (Basic Auth: <api_key>:)
- **Назначение:** Интеграция платформы Imperal Cloud с Apptio Cloudability для автоматизации предметной области: корпоративный финансовый мониторинг облачной инфраструктуры предприятия, оптимизация RI и Savings Plans.

## 2. Решаемая проблема
Когда **FinOps-директор** сталкивается с задачей **корпоративный финансовый мониторинг облачной инфраструктуры предприятия, оптимизация RI и Savings Plans**, возникает необходимость ручного мониторинга, дублирования статусов и переключения между окнами. Это приводит к потере времени, замедлению реакции на инциденты и ошибкам ручного ввода.

## 3. Роли и права доступа
- **FinOps-директор, enterprise-архитектор**
- Принцип наименьших привилегий (Least Privilege): токен запрашивает доступ только к разрешенным операциям чтения и подтвержденным действиям.

## 4. Ключевые сущности
отчеты о затратах (/reporting), рекомендации по инстансам (/recommendations), счета вендоров (/vendors)

## 5. Первичный рабочий сценарий
`загрузка агрегированного счета по облакам -> проверка исполнения годового бюджета -> рассылка алертов`.

## 6. Границы коннектора
- Изолированное хранение секретов (BYOC).
- Никаких фиктивных методов сторонних предметных областей.
- Деструктивные операции требуют явного подтверждения пользователя.
